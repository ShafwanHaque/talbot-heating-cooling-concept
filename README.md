# Talbot Heating & Cooling Website Concept

Standalone outreach concept tailored to the company’s published services and visual identity.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect site: http://www.talbotheatingandcooling.com/
- Official logo and a high-resolution image from the company website are stored locally under `public/brand` and `public/hero`.
- Company details, theme, contact information, and service areas are in `src/config/site.config.ts`. Confirm details with the company before launch.
- The contact form is a preview and does not send submissions. Maps use OpenStreetMap tiles and need an internet connection.
